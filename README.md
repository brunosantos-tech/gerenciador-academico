
# Gerenciador Acadêmico

Aplicação web desenvolvida para organizar atividades, trabalhos,
provas e prazos da faculdade.

## Objetivo

Centralizar as informações acadêmicas em um único lugar,
facilitando o acompanhamento de tarefas e datas de entrega.

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- SQLite (planejado)

## Funcionalidades atuais

- Página inicial com painel acadêmico.
- Estrutura inicial de aplicação web.
- Layout adaptável para diferentes tamanhos de tela.

## Próximas funcionalidades

- Cadastro de atividades acadêmicas.
- Organização por disciplina e tipo.
- Controle de prazos e prioridades.
- Marcação de atividades concluídas.
- Persistência de dados com SQLite.

## Como executar localmente

1. Instale o Python e o Git.
2. Crie um ambiente virtual.
3. Instale o Flask.
4. Execute `python app.py`.
5. Acesse `http://127.0.0.1:5000` no navegador.
